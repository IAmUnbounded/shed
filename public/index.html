Share from iPhone

Send an Instagram post, a TikTok, a video or any link to Shed from the share sheet. Shed downloads the post and its caption, and an agent starts on it.

  1. Easiest, on the Mac: tap Add it on this Mac, then Add Shortcut. iCloud puts it on your iPhone too. Or tap Get the Shortcut: on the Mac it shows a code to scan with the iPhone camera; on the iPhone it shows a link to paste into Safari, or how to build the Shortcut by hand.
  2. In Instagram, tap the paper plane under a post, swipe the bottom row to Share (the square with an arrow), then scroll down the list to Send to Shed. If it isn't there, tap Edit Actions… at the bottom and turn it on.
  3. Say what you want done with it, or leave it blank.

Already downloaded it? Open the Files app → Browse → Downloads, tap Send to Shed, then Add Shortcut. No Files or Shortcuts app? Both are free from Apple in the App Store.

1. Get it through Safari. The Home Screen app can't install Shortcuts, so:

  1. Tap Copy link below.
  2. Open the Safari app, paste the link into the address bar and go.
  3. Tap Download. Nothing seems to happen: that's normal.
  4. Open the Files app → Browse → Downloads and tap Send to Shed. The Shortcuts app opens.
  5. Tap Add Shortcut.

The link works once, for 5 minutes. Get a new one any time.

2. Or build it by hand (no download)
  1. In Shortcuts, tap +, name it Send to Shed. Tap the ⓘ (or the name ▾ → Details) and turn on Show in Share Sheet.
  2. Add Ask for Input. Prompt: What should Shed do with it?
  3. Add Get Contents of URL. Paste the address: . Tap ▸ to show more: Method POST. Headers: add Authorization with the value . Request Body JSON: add a Text field shared set to Shortcut Input, and a Text field note set to Provided Input.
  4. Add Show Notification with Contents of URL.

Scan this with your iPhone's camera, tap the link, then tap Add Shortcut. It works once, for 5 minutes.

Local model

Laya source ↗

A branch per session

A new session started in a git project works on a branch of its own (shed/…) in its own checkout under Shed Workspaces/branches, so agents working on the same repository never change each other's files. Review, commit, push and open a pull request from the session's Changes tab.

Harnesses Laya can choose

When Laya picks for you, including messages shared from your iPhone, it only starts or continues sessions in the harnesses ticked here. You can still pick any ready harness yourself, and follow-ups to an existing session go to that session.

Models by harness

Laya chooses among the enabled models for the selected harness. Use model IDs accepted by that harness’s CLI.
